# Десктоп-ассистент «Бомж»

## 1. Описание и назначение
- **Дата создания / инициализации проекта:** 2026-11-15
- **Основная цель:** Компактный, стильный и быстрый десктопный AI-помощник для Windows, вызываемый голосовой командой «Бомж» или горячей клавишей Ctrl + Shift + Space, с выводом стриминговых ответов нейросети в плавающем HUD-окне, процедурным выполнением консольных команд и локальным голосовым ответом Silero TTS.
- **Целевая аудитория и ключевые сценарии:** Пользователь ПК (Хамид); мгновенное получение ответов на вопросы, автономное выполнение процедурных команд в PowerShell (диагностика системы, проверка процессов, файлов, сети) с наглядной однострочной индикацией действий в реальном времени.

## 2. Технический стек и окружение
- **Язык и рантайм:** Python 3.12 (Windows x64)
- **Фреймворки и библиотеки:** PyQt6 6.11, google-genai 3.3, vosk 0.3.45, sounddevice 0.5.6, numpy 2.5, keyboard 0.13, pynput 1.8, torch 2.15.0 (CPU), Silero TTS v5.6 ru, python-dotenv 1.2, pycaw 20260927, comtypes 1.5, uiautomation 2.0.29, playwright 1.65, lxml 6.1
- **Базы данных и брокеры:** Локальное хранение конфигурации (`config.json`, `.env`, реестр Windows `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`)
- **Инфраструктура и деплой:** Фоновый запуск на Windows (System Tray / Background Worker Threads)
- **Ключевые переменные окружения:**
  - `GEMINI_API_KEY` — Основной API-ключ Google Gemini
  - `GEMINI_API_KEYS` — Пул API-ключей через запятую для чередования round-robin на каждый запрос и авторотации при лимитах (429)
  - `DEFAULT_MODEL` — Основная модель (gemini-3.5-flash-lite)
  - `SECONDARY_MODEL` — Вторая модель (gemini-4-hydrogen)
  - `WAKE_WORD` — Ключевое слово активации («бомж»)
  - `HOTKEY` — Глобальная комбинация клавиш (ctrl+shift+space)

## 3. Архитектура и структура проекта
- **Архитектурный подход:** Модульная событийно-ориентированная архитектура (Event-driven) с поддержкой автономного агентного цикла инструментов (Function Calling / Tools), разделением потоков ввода (аудио, хоткеи, глобальный клик-хук pynput), бизнес-логики (Gemini Client с AFC, Silero TTS Service, терминальный исполнитель) и интерфейса (PyQt6 HUD оверлей с динамическим баннером активности).
- **Карта ключевых директорий и файлов (Project Map):**
  - `src/tools/terminal.py` — автономный исполнитель консольных команд PowerShell с постоянным фоновым демоном `PowerShellSession` (пайпы stdin/stdout, sentinel-маркеры, задержка 3–20мс вместо 900мс, сохранение сессионного состояния) и резервным запуском через subprocess.
  - `src/tools/fast_launcher.py` — аппаратный семантический роутер намерений `SemanticIntentEngine` (стемминг, синонимы, нечеткое сопоставление, исполнение за 2–5мс без API) для звука, медиа, окон, запуска и завершения процессов Windows.
  - `src/tools/screen.py` — захват экрана за 35мс (JPEG) и мультимодальный анализ Gemini Vision (как превентивно по ключевым словам, так и автономно через вызов инструмента `take_screenshot`).
  - `src/tools/desktop.py` — прямое управление громкостью (точный процент 0-100% через Windows Core Audio endpoint / pycaw), мультимедиа и окнами Windows.
  - `src/tools/clipboard.py` — чтение и запись текста в системный буфер обмена Windows.
  - `src/tools/web_search.py` — надёжный поиск актуальной информации в интернете со сниппетами (Bing + Wikipedia API fallback).
  - `src/tools/ui_automation.py` — прямое управление интерфейсом Windows UI Automation (инспекция окон, программный клик по элементам, ввод текста).
  - `src/tools/browser_control.py` — продвинутое управление Chromium браузерами (Chrome, Edge, Yandex, Brave) через CDP и Playwright, плюс быстрый запуск URL за 2мс.
  - `src/tools/computer_use.py` — компьютерное зрение и клики по координатам (Win32 mouse click, move, drag, keyboard type).
  - `src/core/autostart.py` — управление автозагрузкой при старте Windows (реестр `HKCU Run`).
  - `models/silero/v5_6_ru.pt` — локальная модель нейросетевого синтеза речи Silero TTS v5.6.
  - `src/core/config.py` — управление конфигурацией (.env, config.json), поддержка round-robin чередования API-ключей, настройки моделей и голосов Silero.
  - `src/core/hotkey.py` — глобальный перехват сочетания Ctrl+Shift+Space через keyboard/pynput.
  - `src/services/gemini_service.py` — потоковый клиент Google Gemini API с мультимодальным аудио (`stream_audio_prompt`), прогретым пулом сетевых соединений (Keep-Alive), регистрацией 21 системного инструмента и round-robin ротацией ключей.
  - `src/services/tts_service.py` — локальный потоковый синтезатор речи Silero v5.6 с конвейеризацией предложений (Sentence-Level Streaming TTS), очередями синтеза/воспроизведения (`AudioPlaybackQueue`) и началом озвучки за ~500–700мс.
  - `src/audio/vosk_manager.py` — автозагрузка и безопасная инициализация русской модели Vosk.
  - `src/audio/listener.py` — фоновый захват звука микрофона со сверхбыстрым распознаванием слов-активаторов через нечеткие фонетические алиасы («бомж», «бомжик», «бонж», «бон», «бог», «компьютер», «ассистент»), поддержкой одномоментных команд («бомж открой браузер»), Dynamic VAD с адаптивным порогом шума и паузой 380мс, трансляцией RMS уровня в UI и гарантированным автоскрытием индикаторов по сигналу `listening_stopped`.
  - `src/ui/styles.py` — глассморфизм QSS-стили с блоком для динамической строки активности (`activityBanner`).
  - `src/ui/mic_indicator.py` — компактный анимированный пульсирующий пилл микрофона с векторной отрисовкой, пульсирующим halo-кольцом и эквалайзером волн, реагирующим на реальный RMS микрофона, с реакцией на клик пользователя.
  - `src/ui/hud_window.py` — плавающий frameless оверлей с динамической плашкой активных команд, встроенным In-HUD режимом прослушивания (`HUDListeningBar`), потоковым выводом текста и Sentence-Level Streaming TTS.
  - `src/ui/tray.py` — иконка и контекстное меню в системном трее Windows с галочкой автозагрузки.
  - `tests/` — полный тестовый набор (51 unit-тест, включая проверку распознавания всех алиасов wake-word, устойчивость терминала, семантический роутер, потоковый TTS и Dynamic VAD).
  - `main.py` — точка входа приложения, связывающая сигналы и запускающая цикл событий Qt.
