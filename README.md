# 🎙️ Десктоп-ассистент «Бомж» (Windows)

Умный, компактный и сверхбыстрый локально-облачный десктопный AI-ассистент для Windows 10/11 с голосовым управлением, оверлейным HUD-интерфейсом на PyQt6 и агентным выполнением действий в ОС.

---

## ⚡ Ключевые возможности

1. **Голосовое управление без задержек:**
   - Офлайн-распознавание ключевого слова активации (**«Бомж»**) на базе модели Vosk (Grammar KWS).
   - Динамический VAD (Voice Activity Detection) по уровню энергии микрофона с автокалибровкой шума окружения.
   - Прямая потоковая передача чистого голоса (PCM WAV 16kHz) в мультимодальный вход модели Gemini без промежуточного STT.
   - Поддержка непрерывного диалога (5-секундное окно follow-up) и мгновенных стоп-команд (*«стоп», «остановись», «хватит»*).

2. **Быстрый семантический роутер (`SemanticIntentEngine`):**
   - Перехватывает одиночные тривиальные команды (громкость, закрытие окон, запуск блокнота/калькулятора) локально за **<2 мс**, не тратя токены и время на обращение к облаку.
   - Сложные, составные и исследовательские задачи прозрачно делегирует в Gemini.

3. **Агентные инструменты (22 Function Calling Tools):**
   - **Консоль:** Постоянный прогретый фоновый демон PowerShell (`PowerShellSession`) со временем отклика ~3-20 мс.
   - **Звук и окна:** Прямое управление Windows Core Audio endpoint (pycaw), Win32-медиа и управление активными окнами.
   - **UI Automation & Computer Use:** Инспекция элементов окон через Windows UIA, клики, перемещения мыши и ввод текста через Win32 `SendInput`.
   - **Браузер:** Управление Chromium-браузерами (Chrome, Edge, Brave, Yandex) по протоколу CDP/Playwright.
   - **Веб-поиск:** Интеграция с Bing и Wikipedia API fallback.
   - **Зрение:** Быстрый захват экрана (JPEG ~35 мс) и мультимодальный анализ.

4. **Локальный синтез речи (Silero TTS v5.6):**
   - Sentence-Level Streaming конвейер на базе ONNX/PyTorch CPU.
   - Минимальный Time-to-First-Audio (~500–700 мс) благодаря синтезу предложений на лету во время стриминга токенов.

5. **Интерфейс (PyQt6):**
   - Frameless темный полупрозрачный HUD-оверлей с глассморфизмом.
   - Анимированный пульсирующий векторный индикатор микрофона с динамическим эквалайзером.
   - Кнопка принудительной остановки 🛑 и интеграция в системный трей с автозагрузкой Windows.

## 🛠️ Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/kham1231/Bomz.git
cd Bomz
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка конфигурации
Скопируйте пример файла конфигурации:
```bash
copy config.example.json config.json
copy .env.example .env
```
Укажите ваш API-ключ Google Gemini (`GEMINI_API_KEY`) в файле `.env` или `config.json`.

### 4. Скачивание моделей (офлайн)
- Модель **Vosk** (`vosk-model-small-ru-0.22`) помещается в `models/vosk/`.
- Модель **Silero TTS** (`v5_6_ru.pt`) помещается в `models/silero/`.

### 5. Запуск
```bash
python main.py
```

Горячая клавиша активации по умолчанию: `Ctrl + Shift + Space` или ключевое слово **«Бомж»**.
